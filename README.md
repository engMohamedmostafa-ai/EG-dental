# 🦷 EG Dental - موقع عيادة الأسنان

موقع إلكتروني متكامل وتفاعلي لـ **EG Dental** مخصص لعيادات ومراكز طب الأسنان. تم تصميم الموقع باستخدام أحدث تقنيات الويب ليقدم تجربة مستخدم سلسة وتصميماً متجاوباً يعرض خدمات العيادة بكفاءة على جميع الأجهزة (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).

---

## ✨ المميزات الرئيسية (Features)

* **تصميم متجاوب (Responsive Design):** يتكيف تلقائياً مع مختلف مقاسات الشاشات بفضل مكتبة Bootstrap.
* **واجهة تفاعلية (Interactive UI):** شريط عرض رئيسي (Carousel) مخصص لإبراز خدمات العيادة والعروض.
* **قسم الخدمات الطبية:** عرض تفصيلي لخدمات طب الأسنان مثل زراعة الأسنان (Dental Implants) والتجميل.
* **تنسيق عصري واحترافي:** ملفات CSS مخصصة تمنح الموقع هوية بصرية مريحة للعين وتدعم ثقة الزوار.

---

## 🛠️ التقنيات المستخدمة (Technologies Used)

* **HTML5:** لبناء هيكل صفحات الموقع.
* **CSS3 & Bootstrap 5:** لتنسيق العناصر وجعل التصميم متجاوباً.
* **JavaScript:** لإدارة العناصر التفاعلية وشريط العرض.
